# Family Bakery — Vercel-ready static website

## Files
- `index.html` — complete static site
- `assets/family-bakery-logo.png` — supplied Family Bakery logo

## Deploy on Vercel
1. Put this folder in a GitHub repository, or drag the folder into Vercel's project import flow.
2. Framework preset: **Other** (or leave the detected static setting).
3. Build command: leave empty.
4. Output directory: `.`
5. Deploy.

No server/database is required for the current static version.

## Important photo note
The site includes realistic bakery photography and a direct Google Maps link for the business's customer photos/reviews. I did not embed third-party Google customer photos directly because Google-hosted review photos generally require the appropriate Maps/Places integration and permissions.
